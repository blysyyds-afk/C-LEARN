原理讲解：C语言程序结构

欢迎来到C语言的世界。在写第一个程序之前，我们先搞懂一个最核心的问题： 一个C程序到底是由什么组成的？它又是怎么运行起来的？

一、先看一个最简单的C程序

// 引入标准输入输出头文件
#include <stdio.h>

// 主函数，程序唯一入口
int main()
{
    // 在屏幕上输出一行文字
    printf("Hello, World!");

    // 程序正常结束，返回0
    return 0;
}

二、逐行拆解：每一行都在做什么？

1. #include <stdio.h> —— 工具箱的钥匙

就像你要画画得先打开画笔盒，printf、scanf这些输入输出函数都放在stdio.h这个"工具箱"里。 这行代码的作用就是告诉编译器："把stdio工具箱给我拿来，我要用里面的工具。"

2. int main() —— 程序的大门

main函数是C程序唯一的入口。无论程序有多长、有多少个函数，电脑永远从main函数的第一行开始执行。 前面的int表示这个函数执行完会返回一个整数，用来告诉操作系统程序运行得是否正常。

3. 花括号 { } —— 代码的边界

一对花括号括起来的部分叫做"代码块"，表示这是一个整体。main函数的所有执行语句都要写在这对花括号里面。

4. printf("Hello, World!"); —— 真正干活的语句

这是一条执行语句，作用是在控制台屏幕上输出双引号里的内容。
⚠️ 注意末尾的分号 —— 它就像一句话的句号，表示这条指令到此结束。漏掉分号程序会报错。

5. return 0; —— 程序的收尾

表示main函数执行完毕，返回数值0给操作系统。在C语言的约定里，返回0代表程序正常退出， 返回非0代表程序异常结束。

三、入门必守的三条铁律

✅ 铁律一：C语言区分大小写，Main和main是完全不同的两个东西

✅ 铁律二：每条执行语句必须以分号结尾

✅ 铁律三：所有符号都必须是英文半角符号

四、新手最容易踩的坑

❌ 常见错误1：把分号写成中文分号；
❌ 常见错误2：漏掉句尾的分号
❌ 常见错误3：把main写成Main或者MAIN
❌ 常见错误4：花括号不配对，有头没尾

五、思考一下

既然程序从main开始执行，那如果我写了两个main函数会发生什么？printf为什么要放在stdio.h里？ 带着这些问题，我们进入下一个模块的学习。

关键拆解

main 函数的返回值
return 0 代表程序正常退出，非0代表异常。操作系统会接收这个返回值， 用来判断程序是否运行成功。这是一种程序和系统的对话方式。
printf 格式符
%d输出整型、%f输出浮点型、%c输出字符、%s输出字符串。 格式符和后面的变量要一一对应，类型不匹配会输出乱码。
头文件的本质
头文件里只有函数声明，没有具体实现。真正的实现放在库文件里， 链接阶段会把库文件的代码整合到你的程序中。
注释的正确用法
注释不参与编译，是写给人看的。好的代码注释说明"为什么这么做"， 而不是复述"代码在做什么"。
