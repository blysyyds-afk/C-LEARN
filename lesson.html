原理讲解：C语言程序结构Theory: C Program Structure

欢迎来到C语言的世界。在写第一个程序之前，我们先搞懂一个最核心的问题： Welcome to C language. Before writing your first program, let's answer one core question: 一个C程序到底由什么组成？它又是怎么运行起来的？What makes up a C program, and how does it run?

一、先看一个最简单的C程序1. A simplest C program

// Include standard I/O header file
#include <stdio.h>

// Main function, the only entry of program
int main()
{
    // Print text to console
    printf("Hello, World!");

    // Program exits normally with code 0
    return 0;
}

二、逐行拆解：每一行都在做什么？2. Line by line breakdown

1. #include <stdio.h> —— 工具箱的钥匙1. #include <stdio.h> — The key to the toolbox

就像你要画画得先打开画笔盒，printf、scanf这些输入输出函数都放在stdio.h这个"工具箱"里。这行代码的作用就是告诉编译器："把stdio工具箱给我拿来，我要用里面的工具。" Like opening a pencil box before drawing. printf and scanf live in the stdio.h "toolbox". This line tells the compiler: "Bring me the stdio toolbox."

2. int main() —— 程序的大门2. int main() — The gateway of the program

main函数是C程序唯一的入口。无论程序有多长、有多少个函数，电脑永远从main函数的第一行开始执行。前面的int表示这个函数执行完会返回一个整数，用来告诉操作系统程序运行得是否正常。 main() is the only entry point. No matter how long the program is, it always starts from main(). The int before means it returns an integer to tell the OS if it ran successfully.

💭 思考：既然程序从main开始执行，那如果写了两个main函数会发生什么？ Think: What happens if you write two main functions?

关键拆解Key Breakdown

main 函数的返回值main() return value
return 0 代表程序正常退出，非0代表异常。操作系统会接收这个返回值，用来判断程序是否运行成功。 Return 0 = normal exit, non-zero = error. OS receives this code to check execution status.
printf 格式符printf format specifiers
%d输出整型、%f输出浮点型、%c输出字符、%s输出字符串。格式符和后面的变量要一一对应。 %d for int, %f for float, %c for char, %s for string. Must match variable types.
