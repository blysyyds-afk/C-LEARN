原理讲解：C语言程序结构Theory: C Program Structure

欢迎来到C语言的世界。在写第一个程序之前，我们先搞懂一个最核心的问题： Welcome to C language. Before writing your first program, let's answer one core question: 一个C程序到底由什么组成？它又是怎么运行起来的？What makes up a C program, and how does it run?

一、先看一个最简单的C程序1. A simplest C program

// Include standard I/O header file
#include <stdio.h>

// Main function, the only entry of program
int main()
{
    // Print text to console
    printf("Hello, World!");

    // Program exits normally with code 0
    return 0;
}

二、逐行拆解：每一行都在做什么？2. Line by line breakdown

1. #include <stdio.h> —— 工具箱的钥匙1. #include <stdio.h> — Key to the toolbox

就像画画前要打开画笔盒，printf、scanf这些函数都放在stdio.h这个"工具箱"里。这行代码告诉编译器："把stdio工具箱拿来。" Like opening a pencil box before drawing. printf and scanf live in stdio.h. This line tells the compiler: "Bring me the stdio toolbox."

2. int main() —— 程序的大门2. int main() — Gateway of the program

main函数是C程序唯一的入口。无论程序多长，永远从main的第一行开始执行。int表示执行完返回一个整数，告诉系统运行是否正常。 main() is the only entry point. It always starts from main(). The int means it returns an integer to tell the OS if it ran successfully.

💭 思考：既然程序从main开始执行，那如果写了两个main函数会发生什么？ Think: What happens if you write two main functions?

关键拆解Key Breakdown

main 函数的返回值main() return value
return 0 代表程序正常退出，非0代表异常。操作系统接收这个返回值判断运行状态。 Return 0 = normal exit, non-zero = error. OS receives this code to check status.
printf 格式符printf format specifiers
%d整型、%f浮点型、%c字符、%s字符串。格式符和变量要一一对应。 %d for int, %f for float, %c for char, %s for string. Must match variable types.
